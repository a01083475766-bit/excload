# ONECLOAD 랜딩페이지 구조와 디자인 원칙

## 목적

ONECLOAD 랜딩페이지는 완성된 서비스를 판매하는 페이지가 아니라, 온라인 판매자가 개발 중인 주문 업무 자동화 기능을 이해하고 관심 기능과 이메일을 남기는 사전 신청 페이지입니다.

## 정보 구조

1. 헤더: 브랜드와 핵심 이동 버튼만 제공
2. 히어로: 반복 주문 입력 문제와 개발 중인 기능의 방향 제시
3. 업무 흐름 시연: 카카오톡 주문 메시지가 정리되고 택배 엑셀 한 행으로 이어지는 흐름
4. 문제 공감: 주문이 늘수록 반복되는 실제 업무 문장
5. 준비 중인 기능: 각 기능의 작업 전후와 개발 상태
6. 이메일 신청: 관심 기능, 이메일, 참여 방식, 동의 항목을 입력하고 로컬 완료 상태 표시
7. 푸터: 브랜드, 간단 설명, 개인정보 처리 안내, 문의 이메일

## 디자인 원칙

- 흰색과 옅은 중성 배경, 진한 먹색 텍스트, 청록 계열 브랜드 강조색을 사용합니다.
- 장식용 대시보드 대신 실제 주문 정리 업무를 연상시키는 표, 행, 파일, 얇은 선을 중심으로 표현합니다.
- 기능은 현재 사용할 수 있는 것처럼 과장하지 않고, 베타 준비 중·개발 중·설계 중 상태를 명확히 표시합니다.
- 모바일에서는 모든 콘텐츠가 한 열로 흐르고, 작은 화면에서 가로 스크롤이 생기지 않도록 구성합니다.
- 폼은 키보드만으로 사용할 수 있으며, 오류 메시지는 색상뿐 아니라 문장으로 안내합니다.
