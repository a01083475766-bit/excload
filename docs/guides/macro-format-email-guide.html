매크로양식 이용 안내

택배·물류 변환을 써 보셨는데 열이 맞지 않거나, 결과가 비거나, 본인만 쓰는 엑셀 구조라면 매크로양식에서 원하는 열과 순서를 직접 지정해 변환할 수 있습니다.

1. 왜 매크로양식이 생겼나요?

기존 택배·물류 변환

쇼핑몰·택배사·물류센터에서 쓰는 일반적인 업로드 양식에 맞춰 자동으로 열을 연결합니다. 많은 경우에 잘 동작합니다.

그래도 잘 안 되는 경우

거래처·내부 관리용처럼 열 이름·순서가 제각각인 파일은 자동 연결만으로는 원하는 결과가 나오기 어렵습니다.

매크로양식은 이런 분들을 위해, 사용자 지정양식으로 출력 열을 직접 만들고 같은 방식으로 주문 파일을 변환·다운로드하는 메뉴입니다.

2. 이런 분께 권합니다

  • 택배·물류 변환 결과가 비어 있거나, 열이 엉뚱하게 들어간 경우
  • 택배사 공식 양식이 아니라, 거래처·자체 관리용 엑셀이 필요한 경우
  • 자주 쓰는 “나만의 정리 양식”(흔히 매크로처럼 쓰는 파일)이 있는 경우

4. 사용 순서 (사용자 지정양식)

  • 매크로양식 메뉴로 이동합니다.
  • 하단 사용자 지정양식 등록을 누릅니다.
  • 사용자 지정양식 만들기에서 샘플 주문 파일(헤더가 있는 엑셀)을 올립니다.
  • 원본 열 → 출력 열 이름·순서를 맞춘 뒤 저장합니다.
  • 같은 구조의 주문 파일을 다시 첨부해 미리보기를 확인하고 다운로드합니다.

5. 「이 파일 헤더 전용」이란?

지정양식은 등록할 때 올린 주문 파일의 헤더 이름·순서에 맞춰 연결됩니다. 다른 구조의 파일을 올리면 값이 비어 보일 수 있습니다.

6. 한눈에 보는 팁

잘 되는 방법

지정양식 등록에 쓴 파일과 헤더가 같은 주문 파일을 올립니다. 필요하면 고정 입력으로 공통값을 채웁니다.

택배·물류와의 차이

매크로에서 만든 지정양식은 매크로양식 페이지 전용입니다. 일반 택배사·물류 업로드 양식은 각 메뉴에서 따로 등록합니다.
