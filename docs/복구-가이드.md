|------|------------------|

## 2. 환경 변수 백업 방법

### 2-1. Vercel (운영·프리뷰 — 가장 중요)

1. [Vercel Dashboard](https://vercel.com) → 프로젝트 `excload` 선택
2. **Settings → Environment Variables**
3. Production / Preview / Development 각 환경의 변수를 **별도 안전한 저장소**에 기록
   - 권장: 암호 관리자 (1Password, Bitwarden 등)
   - 대안: 암호화된 로컬 파일 (Git·클라우드 동기화 폴더에 두지 말 것)
4. **절대 GitHub Issues, Notion 공개 페이지, 카톡에 붙여넣지 말 것**

CLI로 목록만 확인 (값은 민감 정보이므로 화면 캡처 주의):

```powershell
npx vercel env ls
```

특정 변수 값은 대시보드에서만 확인 가능합니다. 정기적으로 **변수 이름 목록**이라도 백업해 두세요.

### 2-2. 로컬 `.env.local` (로컬 개발 시)

로컬에서 쓸 경우 프로젝트 루트에 생성합니다. Git에 커밋하지 않습니다.

```powershell
Copy-Item .env.example .env.local
# 이후 .env.local 값을 채움
```

백업 방법:

- 암호 관리기에 `.env.local` 전체 내용을 **Secure Note**로 저장
- 또는 USB·암호화 ZIP에만 보관 (Google Drive 일반 동기화 폴더 비권장)

### 2-3. 환경 변수 전체 목록 (백업 시 체크용)

`.env.example`에 있는 항목 + 코드에서 추가로 참조하는 항목입니다.  
**이름만** 백업 목록으로 두고, 값은 각 서비스 콘솔·Vercel에서 확인하세요.

#### 필수 (서비스 가동)

| 변수명 | 용도 |
|--------|------|
| `DATABASE_URL` | PostgreSQL 연결 (Prisma) |
| `DIRECT_URL` | PostgreSQL 직접 연결 (마이그레이션·풀링) |
| `NEXTAUTH_SECRET` | NextAuth 세션 암호화 |
| `NEXTAUTH_URL` | OAuth 콜백 기준 URL (끝 `/` 없이) |

#### 인증 · OAuth

| 변수명 | 용도 |
|--------|------|
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Google 로그인 |
| `KAKAO_CLIENT_ID` / `KAKAO_CLIENT_SECRET` | Kakao 로그인 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | Naver 로그인 |
| `ADMIN_EMAIL` / `ADMIN_EMAILS` | 관리자(akman) 접근 |
| `ADMIN_BCRYPT_HASH` | 관리자 비밀번호 해시 |
| `ADMIN_CREATE_SECRET` | 관리자 계정 생성 API |

#### 결제

| 변수명 | 용도 |
|--------|------|
| `STRIPE_SECRET_KEY` | Stripe API |
| `STRIPE_WEBHOOK_SECRET` | Stripe 웹훅 검증 |
| `STRIPE_MONTHLY_PRICE_ID` / `STRIPE_YEARLY_PRICE_ID` | 구독 Price ID |
| `TOSS_SECRET_KEY` | 토스 서버 시크릿 |
| `NEXT_PUBLIC_TOSS_CLIENT_KEY` | 토스 클라이언트 키 (브라우저) |
| `NEXT_PUBLIC_TOSS_PAYMENTS_CLIENT_KEY` | 토스 클라이언트 키 (대체 이름) |

#### 메일 · 문의

| 변수명 | 용도 |
|--------|------|
| `RESEND_API_KEY` | 비밀번호 재설정·메일 발송 |
| `EMAIL_FROM` / `PASSWORD_RESET_EMAIL_FROM` | 발신 주소 |
| `PASSWORD_RESET_CODE_SECRET` | 재설정 코드 해시 (선택) |
| `CONTACT_ADMIN_EMAIL` | 문의 수신 메일 |

#### AI · 파이프라인

| 변수명 | 용도 |
|--------|------|
| `OPENAI_API_KEY` | OpenAI API |
| `AI_MODEL` / `AI_API_URL` | 모델·엔드포인트 (선택) |
| `NEXT_PUBLIC_AI_ENABLED` | AI 기능 on/off |
| `AI_ALLOW_ANONYMOUS_TRIAL` | 비로그인 AI 체험 |
| `AI_NORMALIZE29_MAX_TOKENS` | normalize-29 토큰 상한 |

#### Cron · 내부 API

| 변수명 | 용도 |
|--------|------|
| `CRON_SECRET` | Vercel Cron 인증 (`vercel.json` 스케줄) |
| `WEBHOOK_INTERNAL_SECRET` | 내부 플랜·포인트 API |

#### 커머스 리포트 (관리자 전용, `/akman/commerce-report`)

| 변수명 | 용도 |
|--------|------|
| `NAVER_SHOPPING_CLIENT_ID` / `NAVER_SHOPPING_CLIENT_SECRET` | 네이버 쇼핑 검색 API (실시간 참고 조회, DB 저장 없음). Naver 로그인용 `NAVER_CLIENT_ID`/`NAVER_CLIENT_SECRET`과는 별개 애플리케이션 키. |

#### 기타

| 변수명 | 용도 |
|--------|------|
| `NEXT_PUBLIC_BASE_URL` | 공개 기준 URL |
| `TRIAL_IP_SALT` / `FREE_BENEFIT_SALT` | 체험·무료 혜택 지문 |
| `TRIAL_BYPASS_IPS` | 체험 IP 화이트리스트 (선택) |
| `EXCLOUD_DEBUG_PIPELINE` / `NEXT_PUBLIC_EXCLOUD_DEBUG_PIPELINE` | 파이프라인 디버그 |

`CRON_SECRET` 등록 스크립트: `scripts/set-vercel-cron-secret.ps1` (값은 콘솔에 출력하지 않음).

## 3. GitHub에 없는 중요 파일·자산 목록

### 3-1. `.gitignore`로 의도적으로 제외된 항목

| 경로/패턴 | 중요도 | 설명 |
|-----------|--------|------|
| `.env` | **최상** | 비밀 환경 변수 (로컬) |
| `.env.local` | **최상** | Next.js 로컬 오버라이드 (관례상 미커밋) |
| `node_modules/` | 낮음 | `npm install`로 재생성 |
| `.next/` | 낮음 | `npm run build`로 재생성 |
| `.vercel/` | 중간 | Vercel 프로젝트 링크 정보 (`vercel link`) |
| `docs/local/` | 중간 | Cursor·AI 로컬 메모 (기기별 상이) |
| `렌딩페이지/` | 중간 | 랜딩 기획·이미지·초안 |
| `logs/`, `*.log` | 낮음 | 실행 로그 |
| `tsconfig.tsbuildinfo` | 낮음 | TS 증분 빌드 캐시 |
| `_onekl-no01_extracted/`, `onekl-no01.zip` | 참고 | 과거 비교용 백업 |
| `.tmp.driveupload*` | 낮음 | Google Drive 동기화 임시 |

### 3-2. GitHub에 있지만 “데이터”는 별도 백업 필요

| 항목 | 설명 |
|------|------|
| `prisma/migrations/` | 스키마 변경 이력 (Git에 있음) |
| `prisma/dev.db` | SQLite 파일이 Git에 포함되어 있으나, **현재 스키마는 PostgreSQL** — 운영 DB 대체 불가 |
| **PostgreSQL 실제 데이터** | 사용자·결제·포인트 등 — **반드시 DB 제공업체에서 백업** |

### 3-3. 저장소 밖에서만 관리되는 자산 (복구 시 필수 확인)

| 서비스 | 백업·기록 대상 |
|--------|----------------|
| **Vercel** | 환경 변수, 도메인, Cron, 배포 이력 |
| **PostgreSQL** (Neon/Supabase/Railway 등) | 자동 백업 설정, Connection string |
| **Stripe** | API 키, Webhook endpoint URL, Price/Product ID |
| **토스페이먼츠** | 가맹점 키, 빌링키, 웹훅 URL |
| **Google / Kakao / Naver** | OAuth Client ID·Secret, Redirect URI |
| **Resend** | API 키, 발신 도메인 DNS |
| **OpenAI** | API 키, 사용 한도 |
| **도메인 DNS** | `excload.com` / `www` CNAME·리다이렉트 (`next.config.ts` 참고) |

## 4. 복구 절차 (단계별)

### Step A — 소스 코드 복구

```powershell
git clone https://github.com/a01083475766-bit/excload.git
cd excload
git checkout main
git pull origin main
```

확인:

```powershell
git status          # clean 여부
Test-Path package.json
Test-Path prisma/schema.prisma
```

### Step B — Vercel 재연결 (배포만 사용하는 경우)

1. Vercel에서 GitHub 저장소 `excload` 연결 확인
2. **Environment Variables**를 백업본·콘솔 기준으로 복원
3. Production **Redeploy**
4. `vercel.json` Cron 경로 동작 확인:
   - `/api/cron/toss-subscription-renew` (매일 18:00 UTC)
   - `/api/cron/purge-withdrawn-accounts` (매일 19:30 UTC)

### Step C — 데이터베이스

1. PostgreSQL 인스턴스 접속 정보(`DATABASE_URL`, `DIRECT_URL`) 확인
2. 마이그레이션 적용 (배포 파이프라인에 없으면 수동):

```powershell
npm install
npx prisma migrate deploy
```

3. DB 스냅샷이 있다면 제공업체 콘솔에서 **Restore** 후 connection string 갱신

### Step D — 외부 서비스 콜백 URL 재설정

운영 도메인 기준 (예: `https://www.excload.com`):

| 서비스 | 확인 URL |
|--------|----------|
| NextAuth OAuth | `{NEXTAUTH_URL}/api/auth/callback/{provider}` |
| Stripe Webhook | `{도메인}/api/stripe/webhook` |
| 토스 | 빌링·결제 성공/실패 리다이렉트 URL |

### Step E — 로컬 개발이 필요할 때만

```powershell
npm install
Copy-Item .env.example .env.local
# .env.local 편집 후
npm run dev
```

배포만 사용한다면 Step A + B + C + D로 충분합니다.

### Step F — 복구 후 검증

- [ ] 메인 페이지 로드
- [ ] 이메일·소셜 로그인
- [ ] 주문/엑셀 변환 핵심 플로우
- [ ] 구독·결제 (테스트 모드 또는 소액)
- [ ] 비밀번호 재설정 메일
- [ ] 관리자(akman) 페이지 접근
- [ ] Vercel Cron 로그 (구독 갱신·탈퇴 계정 정리)

## 5. 자주 하는 실수

1. **GitHub만 복구하고 Vercel env를 안 넣음** → 빌드는 되도 로그인·DB 전부 실패
2. **`NEXTAUTH_URL` 끝에 `/` 포함** → OAuth 실패 (`auth.ts`에서 슬래시 제거 경고)
3. **DB 마이그레이션 미적용** → Prisma 런타임 오류
4. **Stripe/토스 웹훅 URL 미갱신** → 결제는 되는데 구독·포인트 미반영
5. **`.env`를 Git에 커밋** → 비밀 유출 — 절대 금지
