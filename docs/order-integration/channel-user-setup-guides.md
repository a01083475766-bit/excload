# 채널별 사용자 연결 안내 (초안)

> **문서 목적**: 비개발자 판매자가 **실제 화면을 보며 따라 할 수 있는** 연결 안내 초안.
> **작성**: 2026-07-17 · 조사 단계 초안 (UI·코드 미반영)
> **원칙**: 사용자가 **입력할 값**과 **복사해 붙여넣을 값**을 구분한다. **사용자가 하지 않아도 되는 항목**도 명시한다. 아직 직접 연결할 수 없는 채널은 **거짓 안내 대신 준비 상태·이유**를 표시한다.
> **연관**: [channel-api-access-matrix.md](./channel-api-access-matrix.md) (판정·근거) · [channel-api-research-sources.md](./channel-api-research-sources.md) (출처)

## 표기 규칙

- ✍️ **직접 입력**: 판매자가 값을 타이핑
- 📋 **복사→붙여넣기**: 채널에서 발급된 값을 엑클로드에 붙여넣기
- 🚫 **하지 않아도 됨**: 이 채널에서 불필요한 항목
- ⚠️ **확인 필요**: 공식 공개 문서로 확정하지 못함

## 엑클로드 공통 정보 (사용자에게 보여줄 값)

| 항목 | 값 |
|------|-----|
| 업체명 | 엑클로드 |
| 서비스 URL | https://www.excload.com |
| API 호출 고정 IP | `NEXT_PUBLIC_EXCLOAD_OUTBOUND_IP` (예: 54.180.45.46) |

## 1. 쿠팡 (연결 가능 · live)

**① 연결 전에 필요한 것**: 쿠팡 WING 판매자 계정(사업자 인증 완료), 로그인 권한

**② 어디에 로그인**: 쿠팡 WING → https://wing.coupang.com

**③ 어느 메뉴로 이동**: 우측 상단 아이디 클릭 → 판매자정보(또는 추가판매정보) → OPEN API 키 발급

**④ 무엇을 신청/발급**: 약관 동의 → 키 사용 목적 **OPEN API** 선택 → 다음 중 택1
- **연동업체 선택**: 목록에 엑클로드가 있으면 선택 (IP 입력 불필요)
- **자체개발(직접입력)**: 목록에 없을 때. ✍️ 업체명(엑클로드), 서비스 URL(https://www.excload.com), 📋 **API 호출 IP**(엑클로드 고정 IP, 최대 10개) 입력

**⑤ 엑클로드 정보 입력 위치**: 연결 화면 왼쪽 입력란

**⑥ 엑클로드에 붙여넣을 값**: 📋 업체코드(vendorId), 📋 Access Key, 📋 Secret Key

**⑦ 연결 테스트**: 값 저장 후 "연결 테스트"

**⑧ 자주 발생하는 오류**: IP 미등록/오등록 시 인증 실패, 연동정보 수정 **주 10회 제한** 초과

**⑨ 현재 확인 수준**: 확정(공식 문서). 🚫 Redirect URI 불필요

## 2. 스마트스토어 (연결 가능 · beta) — 내 스토어 애플리케이션

> ⚠️ 이 안내는 **내 스토어 애플리케이션** 방식입니다. 커머스솔루션마켓(솔루션 사업자) 방식과 **다릅니다**(D절 참고).

**① 연결 전에 필요한 것**: 스마트스토어 판매자 계정, 해당 스토어의 **통합매니저 권한**

**② 어디에 로그인**: 커머스API센터 → https://apicenter.commerce.naver.com (스마트스토어센터에서 진입해도 커머스API센터로 이동)

**③ 어느 메뉴로 이동**: [애플리케이션 > 내스토어 애플리케이션] → 애플리케이션 등록

**④ 무엇을 신청/발급**: 스토어 선택 → 앱 이름·설명 입력 → **API 선택(주문 관련 권한 포함)** → 등록 → **애플리케이션 ID / 시크릿** 확인. 필요 시 **API 호출 IP** 등록(엑클로드 고정 IP)

**⑤ 엑클로드 정보 입력 위치**: 연결 화면 왼쪽 입력란

**⑥ 엑클로드에 붙여넣을 값**: 📋 Client ID(애플리케이션 ID), 📋 Client Secret(시크릿). ✍️ type은 기본 **SELF**

**⑦ 연결 테스트**: 저장 후 "연결 테스트" (엑클로드가 전자서명·토큰 발급을 처리)

**⑧ 자주 발생하는 오류**: 요청 Content-Type이 `application/json`이면 실패(내부 처리는 `x-www-form-urlencoded`), 통합매니저 권한 없으면 앱 조회 불가. **API 호출 IP는 한 애플리케이션에 최대 3개**(직접 확인). 이미 앱이 있으면 새 앱 등록 없이 **기존 앱의 API 호출 IP에 엑클로드 IP만 추가**

**⑨ 현재 확인 수준**: 확정. 🚫 서비스 URL·Redirect URI 불필요. ⚠️ IP 등록 필수 여부는 화면 기준 재확인

## 3. 11번가 (연결 가능 · beta)

**① 연결 전에 필요한 것**: 11번가 셀러오피스 판매자 계정

**② 어디에 로그인**: 11번가 셀러오피스

**③ 어느 메뉴로 이동**: 셀러오피스 화면 **최하단 'OpenAPI' 버튼** → 11번가 OPEN API CENTER → [서비스 등록/확인]

**④ 무엇을 신청/발급**: 사용자 정보 입력 후 서비스 등록 → **11ST OPEN API KEY(32자리)** 확인. ⚠️ [API KEY 관리 > 인증하기] / [접속권한 > 셀링툴 업체 선택]에서 **엑클로드 선택이 필요한지 공식 확인 필요**

**⑤ 엑클로드 정보 입력 위치**: 연결 화면 왼쪽 입력란

**⑥ 엑클로드에 붙여넣을 값**: 📋 11ST OPEN API KEY

**⑦ 연결 테스트**: 저장 후 "연결 테스트"

**⑧ 자주 발생하는 오류**: 미등록 키(`unregisteredKey`), 일 호출 초과(`overedTraffic`), 접근 거부(`accessDeny` — 셀링툴/권한 미설정 가능)

**⑨ 현재 확인 수준**: 조건부. 🚫 Redirect URI 불필요. ⚠️ 셀링툴 선택·IP 요건 공식 확인 필요

## 4. 카페24 (연결 가능 · beta)

**① 연결 전에 필요한 것**: 카페24 쇼핑몰 계정 + **카페24 개발자센터** 가입(현재 베타는 판매자가 자기 앱 생성)

**② 어디에 로그인**: 카페24 개발자센터 → https://developers.cafe24.com

**③ 어느 메뉴로 이동**: 앱 생성(App) → 인증 정보

**④ 무엇을 신청/발급**: App 생성 → **Client ID / Client Secret** 확인 → **Redirect URI**에 아래 값 등록 → Scope에 **mall.read_order** 포함

**⑤ 엑클로드 정보 입력/등록 위치**:
- 개발자센터 앱: 📋 Redirect URI = `https://www.excload.com/api/order/integration/cafe24/callback`
- 엑클로드 연결 화면 왼쪽 입력란

**⑥ 엑클로드에 붙여넣을 값**: 📋 쇼핑몰 ID(mallId), 📋 Client ID, 📋 Client Secret

**⑦ 연결 테스트**: 값 저장 → "카페24 연동 시작" → 권한 동의(OAuth) 완료

**⑧ 자주 발생하는 오류**: Redirect URI 불일치(정확히 동일해야 함), scope에 `mall.read_order` 누락, 토큰 만료(access ~2h)

**⑨ 현재 확인 수준**: 확정. 🚫 고정 IP 불필요. ⚠️ 비개발자에게는 개발자센터 앱 생성이 진입장벽 — 안내에 명시 필요

## 7. NHN커머스/샵바이 (연결 가능 · 개발진행중)

> 엑클로드 공용 앱·OAuth·앱스토어 설치가 아닙니다. **판매자 본인 워크스페이스의 개인 연동 앱** systemKey + mallKey 방식입니다.

**① 연결 전에 필요한 것**: 샵바이 워크스페이스·서비스어드민 접근 권한 (앱 등록·개발연동 정보 메뉴)

**② 어디에 로그인**: 워크스페이스(셀러어드민) + 서비스어드민

**③ 어느 메뉴로 이동**:
- systemKey: 셀러어드민 → **앱(App) 등록/수정** → 주문조회 권한 선택 → systemKey 확인
- mallKey: 서비스어드민 → 서비스 관리 → 쇼핑몰 관리 → (쇼핑몰 선택) → 개발연동 정보 → **외부 연동 키**

**④ 무엇을 신청/발급**: 본인 워크스페이스에 **개인 연동 앱 등록 → systemKey** / 서비스어드민에서 **mallKey(외부 연동키)** 확인

**⑤ 엑클로드 정보 입력 위치**: 연결 화면 왼쪽 입력란 (판매자센터에 엑클로드 IP·URL 등록 단계 없음)

**⑥ 엑클로드에 붙여넣을 값**: 📋 systemKey, 📋 외부 연동키(mallKey), (선택) 쇼핑몰 도메인

**⑦ 연결 테스트**: **저장 후** 「연결 테스트」(주문 0건이어도 API 정상 응답이면 연결 확인)

**⑧ 자주 발생하는 오류**: Token Bucket **1초 100회 초과**, systemKey·mallKey **발급 위치 혼동**, 파트너어드민 「외부시스템 연동코드」를 mallKey로 오인

**⑨ 현재 확인 수준**: 확정(개인 키 방식). 🚫 판매자측 고정 IP·Redirect 등록 불필요. 요금제에 따라 메뉴 제공 여부는 다를 수 있음

## 8. 고도몰 (연결 준비 · beta·제휴 필요)

> ⚠️ **엑클로드가 NHN커머스 개발자센터에 제휴사(partner_key)로 등록**되어야 연결됩니다. 준비 완료 전에는 연결 불가.

**① 연결 전에 필요한 것**: 고도몰 쇼핑몰 계정 + (엑클로드측) 제휴사 등록·openhub IP 허용

**② 어디에 로그인**: 고도몰 관리자 / NHN커머스 개발자센터(devcenter.godo.co.kr)

**③ 어느 메뉴로 이동**: 개발자센터 → API 사용 신청(쇼핑몰별 user key)

**④ 무엇을 신청/발급**: 쇼핑몰별 **user key** 신청·승인. (partner_key는 엑클로드가 보유)

**⑤ 엑클로드 정보 입력 위치**: 연결 화면 왼쪽 입력란

**⑥ 엑클로드에 붙여넣을 값**: 📋 사용자키(userKey), ✍️ 쇼핑몰 도메인, (선택) mallSno

**⑦ 연결 테스트**: 저장 후 "연결 테스트"

**⑧ 자주 발생하는 오류**: openhub 호출 IP 미허용(NHN 1:1 문의 필요), Token Bucket 1초 100회 초과(429)

**⑨ 현재 확인 수준**: 조건부. 🚫 사용자는 partner_key 입력 불요. ⚠️ 제휴사 등록·IP 허용은 엑클로드↔NHN 절차

## 9. 메이크샵 (연결 준비 · beta·APP 심사 필요)

> ⚠️ **엑클로드 APP이 메이크샵 개발자센터 심사(영업일 5~10일)를 통과**해야 연결됩니다. 준비 완료 전에는 연결 불가.

**① 연결 전에 필요한 것**: 메이크샵 쇼핑몰 계정 + (엑클로드측) APP 등록·심사·접근 허용 IP

**② 어디에 로그인**: 메이크샵 관리자 / 샵스토어

**③ 어느 메뉴로 이동**: 샵스토어에서 엑클로드 APP 설치 → scope 동의

**④ 무엇을 신청/발급**: 판매자는 **APP 설치·권한 동의**. (Client ID/Secret·IP 등록은 엑클로드가 개발자센터에서 처리)

**⑤ 엑클로드 정보 입력 위치**: 연결 화면 왼쪽 입력란

**⑥ 엑클로드에 붙여넣을 값**: ✍️ shop_uid(상점 ID), (선택) 쇼핑몰 도메인

**⑦ 연결 테스트**: 저장 후 "연결 테스트"(엑클로드가 client_credentials 토큰 발급)

**⑧ 자주 발생하는 오류**: 접근 허용 IP 미등록, 토큰 발급 shop_uid+IP당 **1분 5회** 초과, 주문 조회 **30일·1000건 제한**

**⑨ 현재 확인 수준**: 확정. 🚫 사용자는 Client ID/Secret 입력 불요. ⚠️ APP 심사 완료 전 연결 불가

## 10. CJ온스타일 (연결 준비 · beta·입점 협력사 한정·미확정)

> ⚠️ **입점 협력사 전용**이며 API Path가 아직 확정되지 않았습니다(공식 확인 필요). 일반 셀러 대상 아님.

**① 연결 전에 필요한 것**: CJ온스타일 입점 협력사 계약, 파트너시스템 접근

**②~⑥**: 파트너시스템 → API 정보관리 → 직접개발 + 운영 IP(엑클로드 고정 IP) 등록 → **vendorCode·authenticationKey(60자)** 발급 → 엑클로드에 📋 협력업체코드(6자)·📋 인증키·(선택) 배송타입 코드 입력

**⑦~⑨**: ⚠️ 표준 API Path·조회 기간·호출 제한은 **파트너 Docs(로그인) 확인 필요**. 현재 SSOT는 Path placeholder → **미완성**

# D. 네이버 커머스솔루션마켓 (별도 장기 경로 — 현재 베타 아님)

# E. 허브·엑셀 (보조·직접연동 아님)

- **허브(플레이오토·사방넷·이지어드민)**: 이미 해당 허브를 쓰는 판매자가 허브 API 키로 주문을 엑클로드로 가져오는 **보조 연동**. 메인 수집 대체 아님. 계약·API host 확인 필요
- **엑셀 업로드**: 티몬·위메프 등 공식 주문 API가 없거나 중단된 채널은 판매자센터에서 **주문 엑셀 다운로드 → 엑클로드 업로드**로 대응
